# Thermal Foundation — Materials Library

[![Download Latest](https://img.shields.io/github/v/release/TermiteSound/thermal-foundation-materials-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/TermiteSound/thermal-foundation-materials-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

The core materials library for the Thermal Series, adding ores, alloys, and a shared RF energy system.

![Thermal Foundation — Materials Library Preview](https://cdn.modrinth.com/data/Xvg6q5Wp/0680149f9ab1461d7b4ee836906ea641549014ac_96.webp)

## Features

- New ore types: Copper, Tin, Lead, Silver, Nickel, Platinum
- Alloy system: Bronze, Electrum, Invar, Enderium
- Shared RF energy standard used across tech mods
- Fluids: Glowstone, Ender, Redstone, Crude Oil
- Required by Thermal Expansion, Dynamics, and more

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
